# Jetson Monitoring UI Mock-Up Implementation
Using React.js and a few images from a textile dataset, this project mimics a potential option 
for an operator panel. 

This panel features the following: 
- Alerts when an anomaly exceeds the threshold
- Control panel to adjust the threshold and mock framerate
- Panel for live camera feed
- Message log mockup 
- Cloud status mockup 

## Installation
```bash
git clone https://github.com/i-magician/jetson-monitoring-ui
npm install
```

## Usage
Run the app: 
```bash
npm run dev
```
Docker will be added at a later date.
